# Security Policy

## Supported Versions

Please use the latest version of the application. Security updates and patches are provided only for the `main` branch.

| Version | Supported          |
| ------- | ------------------ |
| `main`  | :white_check_mark: |
| older   | :x:                |

## Reporting a Vulnerability

We take the security of our application very seriously. If you discover a security vulnerability, please follow these guidelines to report it responsibly.

### How to Report

Please **do not** report security vulnerabilities through public GitHub issues.

Instead, please report them using GitHub's **Private Vulnerability Reporting** feature. If that is not available, please contact the repository owner directly.

### What to Include

When reporting a vulnerability, please provide the following information:

- A description of the vulnerability and its potential impact.
- Steps to reproduce the issue (including any payload or specific URL).
- Any potential mitigations or solutions if you know them.

### Response Timeline

We will acknowledge receipt of your vulnerability report as soon as possible and strive to send you regular updates about our progress.

Thank you for helping keep EventDecor secure!
